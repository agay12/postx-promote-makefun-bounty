# post-x-promote-make-your-own-bounty-01

A make.fun bounty entry: one post on X that promotes make.fun's make-your-own-bounty post
(https://x.com/makefunai/status/2124915864336236646), from the entrant's public account, with its own photo.

`main.ts` (Node 22) copies `POST.json` — the address of that post — into the grader's output directory.

Run it the way the grader does:

    mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
